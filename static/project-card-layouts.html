Project card layouts

Twenty treatments for the home page “Projects” section, each rendered with all ten real projects and their live metrics. Nothing on this page animates — no keyframes, no transitions. Hover states change instantly.

01

Static grid

Today’s card, lifted out of the marquee into a plain reflowing grid. The control the other nineteen are judged against.

02

Divider list

No card chrome at all. Hairline rules, one line per project, metrics locked to a right rail.

03

Data table

Treat the section as a dataset. Sortable-looking columns, tabular figures, platform as a tinted pill.

04

Icon tile

App-store posture: big centered artwork, name under it, metrics behind a hairline footer.

05

Numbered index

Drops the icons entirely and leans on typography — oversized accent numerals carry the rhythm.

06

Tinted card

Each card wears its own product colour as a wash, so the grid reads as a palette.

07

Bento mosaic

Reach decides size. Fluent Icons and Symbols take double-width cells; the rest stay compact.

08

Stat first

Inverts the hierarchy: the number is the headline, the project name is the eyebrow, the description is gone.

09

Terminal

Echoes the hero terminal — each project as a command with metric flags. Stays dark in both themes.

10

Sticker

Accent-coloured outline with a hard zero-blur offset shadow. Loud, toy-like, unmistakably clickable.

11

Split panel

Artwork gets its own tinted bay on the left, text keeps a clean rectangle on the right.

12

Watermark

The icon becomes oversized bleed art; the label floats over it in a frosted chip.

13

Dense two-line

Maximum density. Name and numbers only — the whole section fits in two shallow rows.

14

Ticket stub

A perforated stub tears the headline metric off the card body. Notches are punched with page-coloured circles.

15

Proportion bar

Reach as a bar, log-scaled against Fluent Icons’ 1,800,992 installs — a linear scale would flatten every plugin to a sliver.

16

Grouped by platform

Clusters by where the thing actually lives, so Figma plugins stop competing with VS Code extensions.

17

Editorial

Two magazine columns, heavy rules, no artwork. Metrics demoted to small-caps running text.

18

Glass on aurora

Borrows the featured-work aurora as a section backdrop and floats frosted cards on top.

19

Hero plus grid

Promotes the highest-reach project to a full-width banner; the remaining nine stay compact underneath.

20

Monochrome minimal

No icons, borders, or colour, and unrounded figures — testing whether precision reads better than shorthand.
