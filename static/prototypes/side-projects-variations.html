Tools I've made for the communities I design in.

Ten shipped side projects across the Figma and VS Code ecosystems — mostly born from friction in my own workflow, released free for everyone.

Variables Generator

Skip the manual setup — paste a JSON payload and generate an entire Figma variables collection, modes and all, in one click.

Chroma Colors

Turn a list of hex values into published Figma color styles in bulk, instead of creating them one by one.

Colorizer

Reorder a messy palette by hue so your color styles read like a spectrum, not a junk drawer.

Kaleidocode

Design a full VS Code color theme visually in Figma, then export it ready to publish to the marketplace.

Regulator

Find-and-replace for color style names — restructure an entire naming scheme across a library in seconds.

Navigator

Search and preview every color style in a document, even the ones buried deep in nested libraries.

VS Code Icons

Drop any of the official VS Code codicons into your Figma mockups without leaving the canvas.

Fluent Icons

A product icon theme that reskins VS Code's entire UI iconography with Microsoft's Fluent design language.

Min

A minimal light and dark theme that strips syntax highlighting down to the essentials so the code takes center stage.

Symbols

A friendly, geometric file icon theme for VS Code covering hundreds of file types — my most popular extension.
