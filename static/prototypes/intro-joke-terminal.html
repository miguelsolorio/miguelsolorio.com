10

package.json

Config-file format, but every field is yours: the workspaces are your current projects, the peer deps are the two tools you live in, and redesign has no exit condition.

Designing softwarefor builders.

I’m a product designer at Google, currently working on Google Colab.

miguel@seattle — zsh — 80×24

~ cat package.json

{

"name": "miguelsolorio",

"version": "5.1.0",

"workspaces": [

"gemini-cli", "colab"

],

"peerDependencies": {

"figma": "*", "vscode": "*"

},

"scripts": {

"design": "figma && code .",

"redesign": "npm run design"

}

}

// redesign has no exit condition
