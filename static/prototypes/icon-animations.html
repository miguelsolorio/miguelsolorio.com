Icons — 6 Animation Variations

Six looping treatments built on the same idea: the full icon set arranged with varied sizes, moving slowly and smoothly. Icons are shuffled on every load and treated uniformly — no single icon is emphasized. Motion is disabled for prefers-reduced-motion.

01 Orbits 02 Breathing Grid 03 Ripple 04 Floating Field 05 Spiral 06 Weight Shift

Variation 01

Orbits

The keeper from round one, refined: icons of mixed sizes ride four dashed rings at different speeds and directions, counter-rotating to stay upright. Outer rings run slower, and smaller icons sit lighter for a sense of depth.

Variation 02

Breathing Grid

A size-varied grid where every icon breathes on a slow sine — scale and opacity rising and falling together. Phases radiate from the center, so the whole field swells and settles like one organism. 12s cycle.

Variation 03

Ripple

The same grid, but motion travels: a smooth circular wave expands from the center every 12 seconds, gently lifting each icon as it passes through. Like dropping a stone in still water.

Variation 04

Floating Field

Each icon drifts through its own small, slow loop — like dust motes suspended in air. No opacity changes, no pulsing; just continuous weightless motion at 12–15s per icon.

Variation 05

Spiral

Icons arranged along golden-spiral arms, the whole system rotating as one slow plane while every glyph stays upright. Size and opacity taper toward the edges — a galaxy of icons.

Variation 06

Weight Shift

A fixed grid where visual weight slowly migrates: each icon eases between small-and-faint and large-and-present on its own phase, so the composition continuously redistributes without anything jumping. 15s cycle.
