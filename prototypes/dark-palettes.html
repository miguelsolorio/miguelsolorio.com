Dark mode palettes — 10 full-system variations

Each variation re-tones everything the site itself owns — page + ambient, text tiers, accent, links, cards, and the hero terminal's chrome and ANSI hues. The Notebooks and CLI demos keep their fixed product colors (Colab dark #202124, Gemini CLI #131314, periwinkle/lavender/pastel syntax) in every variation, so you're judging each palette against the thing it has to live with. 0 is the shipping palette for reference. "Copy CSS" grabs the full token set.

Token names map to the real hooks: page/ambient → main.css .dark .site-ambient + dark.css body, accent/links → dark.css + hero.css .dark h1, cards → project.css .dark .project, terminal → hero.css .dark .home-hero-current --t-*.
